## What is the fee for Beginner Training courses at Tinitiate AI?
```
The regular fee for Beginner Training courses is ₹15,000, and the current special discount price is ₹10,000 only. This applies to beginner courses such as Java Basics, Python, JavaScript / HTML / CSS, TypeScript, SQL, and Data Structures.
```

Professional courses include programs such as Java Full Stack, React Web Development, Next.js, Angular + .NET, AWS Data Engineering, Snowflake Data Engineering, Azure Data Engineering, GCP Data Engineering, and Visualization.
